
#  Análisis de Ventas

##  Contexto
Este proyecto analiza datos de ventas para identificar patrones de comportamiento, categorías más rentables, regiones con mayores ingresos y clientes más valiosos.

##  Objetivo
Identificar oportunidades de mejora y generar insights que apoyen la toma de decisiones del negocio.

##  Preguntas de negocio
- ¿Qué regiones generan más ingresos?
- ¿Qué categorías venden más?
- ¿Quiénes son los clientes más valiosos?
- ¿Cómo evolucionan las ventas en el tiempo?

##  Herramientas utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Insights principales
- Los ingresos se concentran en un grupo reducido de clientes.
- Algunas regiones presentan menores ingresos y requieren análisis.
- Las categorías más vendidas también generan gran parte de los ingresos.
- En 2018 se observa una caída importante en las ventas.
